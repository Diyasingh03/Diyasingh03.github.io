§ 01

Abstract

I build models, and the systems that keep them running. The sketchbook comes along.

I'm an M.S. Computer Science student at Purdue University (B.S. CS '26, M.S. '27) working where machine learning meets systems software. My strongest languages are C++, Python, and Java: I've written an HTTP/1.1 server on raw POSIX sockets, a Unix shell with job control, and ML pipelines that run in production.

Most recently, at Envita Solutions, I built an end-to-end Python email-classification pipeline that runs as its own Docker service on Azure at 2,000+ emails a minute. I took on-call for it, wrote 180+ tests, and raised accuracy from 60% to 99.12%. Before that I built backends at FractalHive and nRoad, ML research at Purdue, and taught Java to a lecture hall of 400 as Head TA of CS180.

My minors in mathematics and art & design show up as generative graphics, like the figures on this page, which are drawn live in code.

fig. 1 — detections under corruption

Animal detection under corruption ↗

Fine-tuned and benchmarked YOLO, Mask R-CNN, and RT-DETR on 9 animal classes from Open Images under Gaussian blur and JPEG compression. RT-DETR won: best baseline mAP@0.5 (0.788) and the smallest high-blur degradation (−11.2% vs −17.7% for YOLO).

  • Python
  • PyTorch
  • RT-DETR
  • YOLO
  • Mask R-CNN
fig. 2 — expected-value tree
dec 2025

Flip7 AI agent ↗

A dynamic-programming hit/stay agent for the Flip 7 card game: memoized, deck-weighted expected values at every state, action by argmax. Pivoted from Q-learning after diagnosing multi-agent reward instability — the DP agent matched human win rate (50%) over 182 evaluated rounds.

  • Python
  • dynamic programming
  • reinforcement learning
  • game theory

Cycle prediction via exponential-decay-weighted averaging with confidence intervals; one daily AI call with a static fallback so it works offline and inside free-tier limits.

fig. 5 — requests across a thread pool
oct 2024C++

Multi-threaded HTTP server

An HTTP/1.1 server in C++ on raw POSIX sockets, with four concurrency modes: iterative, fork, thread-per-request, and thread pool. Adds CGI execution via fork/exec, HTTP Basic auth, sortable directory listings, SIGCHLD reaping, and request-timing stats.

  • C++
  • POSIX sockets
  • multithreading
  • HTTP/1.1
fig. 6 — fork / exec / pipe
sep 2024C

Custom Unix shell

A Unix-like shell in C with process control, I/O redirection, and pipelines built on fork/exec/wait and POSIX system calls. It has full job control (fg/bg, SIGINT, SIGTSTP) to manage concurrent child processes reliably.

  • C
  • POSIX
  • signals
  • job control
